   146→## Known Issues & Risks
   147→1. **Sandbox Process Limitation**: The development environment aggressively kills background processes when idle, making persistent dev server testing difficult. The production build works correctly.
   148→2. **z-ai-web-dev-sdk Dependency**: AI features (chat consultant, document analysis) use z-ai-web-dev-sdk which only works in this sandbox. For production deployment, replace with Google Gemini API or similar.
   149→3. **No User Accounts System**: Current app uses localStorage for user data. For production, add proper user accounts with email authentication.
   150→4. **SEO**: Single-page app - consider adding static SEO pages for each country for better Google ranking.
