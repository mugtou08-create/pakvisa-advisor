    74→**Status**: ✅ Completed

This unhandled error triggered Next.js's error overlay, completely blocking the page.

    82→- Renamed `Map` import to `MapIcon` via `Map as MapIcon` (line 10 of shared-components-4.tsx)

    95→### Task ID: 20-2 — Fix Screen Movement/Jitter (Up/Down/Left/Right)
    96→**Status**: ✅ Completed
    97→**Priority**: Critical (UX-breaking)
    98→
    99→**Problem**: The webapp's screen moved up and down, left and right — causing jittering/shaking during interaction and scrolling.
   100→
   101→**Root Causes Identified**:
   102→1. **No `overflow-x: hidden`** on `html`/`body` — content could cause horizontal scrollbar
   103→2. **No `overscroll-behavior`** — browser rubber-banding caused unexpected viewport shifts
   104→3. **Global `transition` on ALL elements** (`*, *::before, *::after`) — caused layout thrashing on every render
   105→4. **`Map` icon from lucide-react shadowing JS built-in** in 4 additional files (explore-tab, tools-tab, questionnaire-tab, dialogs)
   106→
   107→**Fixes Applied**:
   108→- **globals.css line 129-138**: Added `overflow-x: hidden` and `overscroll-behavior: none` to `html`; `overflow-x: hidden` and `overscroll-behavior-y: contain` to `body`
   109→- **globals.css line 141-149**: Replaced global `*, *::before, *::after` transition with targeted selector list (`a, button, input, select, .card`, etc.) to eliminate layout thrashing
   110→- **page.tsx line 186**: Added `overflow-x-hidden` to root container, removed `scroll-smooth` (moved to CSS layer)
   111→- **4 files renamed `Map` → `MapIcon`**: explore-tab.tsx (4 usages), tools-tab.tsx (2 usages), questionnaire-tab.tsx (import only), dialogs.tsx (2 usages)
   112→
   113→**Verification**:
   114→- ESLint: 0 errors
   115→- VLM screenshot analysis confirms: no horizontal scrollbar, no overflow, no jitter artifacts
   116→- Agent-browser snapshot: no runtime errors

   118→### Task ID: 20-3 — Fix Featured Destinations Carousel Moving the Screen + Content Cutoff
   119→**Status**: ✅ Completed
   120→**Priority**: Critical (UX-breaking)
   121→
   122→**Problem**: The "Featured Destinations" carousel moved the entire screen when scrolling left/right, and some info was being cut off from view.
   123→
   124→**Root Causes**:
   125→1. `DestinationSpotlight` used `scrollIntoView({ inline: 'center' })` which scrolled the whole page instead of just the carousel container
   126→2. `scroll-smooth` class on carousel containers propagated scroll events to parent elements
   127→3. Negative margin classes (`-mx-4 px-4`, `-mx-1 px-1`) on carousel items caused overflow beyond container bounds
   128→4. Carousels lacked `overflow-hidden` wrappers, allowing content to bleed into the page
   129→
   130→**Fixes Applied**:
   131→- **shared-components-2.tsx**: Replaced `scrollIntoView({ inline: 'center' })` with `container.scrollTo({ left: calculated, behavior: 'smooth' })` — scrolls only the carousel, not the page
   132→- **shared-components-2.tsx**: Removed `scroll-smooth` from Featured Destinations carousel; added `overflow-hidden` to section wrapper
   133→- **shared-components-3.tsx**: Removed `-mx-4 px-4` negative margins from stat cards carousel; removed `scroll-smooth` from alert banner
   134→- **shared-components-4.tsx**: Removed `-mx-1 px-1` negative margins from continent stats carousel
   135→- **shared-components-5.tsx**: Added `overflow-hidden` to `CountryComparisonSwiper` root container
   136→- **explore-tab.tsx**: Added `overflow-hidden` to Quick Explore section wrapper
   137→- **page.tsx**: Added `overflow-x-hidden` to `<main>` content area
